## Neovarch Agent 1.4.5

Desktop dan aplikasi HP sekarang satu versi: 1.4.5. Rilis ini membawa Kantor 3D dengan taman, Kartu Neovarch untuk dibagikan, model gratis lewat 9Router, profil GitHub dengan lampiran, serta tiga widget layar utama dan wake word di HP.

### Sorotan rilis ini

- **Kantor ▸ Perusahaan (alur perusahaan).** Kantor bisa dijalankan seperti perusahaan kecil: bagan organisasi agen (rekrut lewat persetujuan, manajer, jadwal heartbeat, anggaran bulanan per agen dan perusahaan, model per agen), tiket dengan penugasan, komentar, dan pemblokir, persetujuan, biaya, serta Tujuan (misi, pohon tujuan, proyek) dan Rutinitas. Ada di desktop dan di HP (tab Rencana). Mati secara default; tab Perusahaan di HP disembunyikan kalau core di PC belum mendukungnya.
- **Lampiran gambar dari HP diperbaiki.** Core sekarang punya `POST /api/uploads`: foto dari HP tersimpan dan sampai ke model sebagai gambar (model vision) atau catatan + path. Sebelumnya HP menampilkan kartu "uploads · 0 B" dan agen tidak menerima gambarnya. Kalau core di PC masih versi lama, HP menampilkan pesan "PC belum mendukung lampiran — perbarui Neovarch di PC".
- **Scroll chat di HP diperbaiki.** Chat terbuka di pesan terbaru, ikut turun saat balasan mengalir (juga setelah memilih foto atau saat layar berubah ukuran), tidak menarik paksa kalau kamu sedang membaca ke atas, dan ada tombol ↓ dengan jumlah balasan baru.

### Yang baru di desktop

- **Kantor 3D dengan taman.** Ruang kerja agen bergaya ruangan Jepang (three.js, dimuat saat dibuka) dengan label nama, popover per agen, tombol "Kasih tugas", dan tombol 3D/Daftar. Agen yang menganggur sesekali berjalan ke dispenser air lalu kembali ke meja saat ada kerjaan. Kantor sekarang punya pintu geser, engawa, dan taman: agen yang santai kadang keluar duduk di bangku taman lalu bergegas kembali saat ada kerjaan. Ada juga Kantor mini di panel kanan. Tanpa WebGL, Kantor otomatis tampil sebagai daftar.
- **Model per agen.** Setiap agen bisa punya model sendiri dari popover Kantor; perubahan langsung terlihat di PC dan HP.
- **Satu pemilih model** di kolom chat dengan tampilan seperti di HP, plus identitas agen (nama dan warna) di chat, daftar Kantor, dan label 3D.
- **Edit laporan langsung** di panel kanan (Ctrl+Alt+L), bisa dilipat otomatis.
- **9Router: model gratis.** Installer memasang 9Router, menyalakannya, dan menyetel model gratis sebagai default tanpa perlu API key manual. Status 9Router tampil di pemilih model dan di Pengaturan ▸ Model. Kalau model gratis kena batas (HTTP 429) atau sedang down, Neovarch otomatis pindah ke model gratis berikutnya dan memberi tahu di chat.
- **Kartu Neovarch:** tombol "Bagikan kartu" di Kantor membuat kartu bergambar Kantor 3D (gaya Kaca, Gelap, atau Warna; ukuran story dan feed) untuk disimpan atau dibagikan.
- **Profil & Teman (GitHub)** dengan kartu bagikan, serta **lampiran di chat**: gambar, dokumen, dan `@file:` dari folder kerja.
- Tampilan mode terang lebih kontras (WCAG AA) dan beberapa perbaikan kecil (ikon durasi, garis waktu percakapan lebih kalem).

### Yang baru di HP (1.4.5)

- **Tiga widget layar utama** bergaya galeri MIUI/HyperOS: **Aksi cepat** 4×2 (Chat, Suara, + Tugas, Kantor, plus cuplikan Kantor 3D), **Status** 2×2 (PC online/offline, agen bekerja dan menunggu, aktivitas terakhir), dan **Agen** 4×4 (daftar agen dengan status; ketuk untuk membuka atau kasih tugas). Mode terang dan gelap.
- **Kartu Neovarch:** tombol "Pamerkan" di Profil dan ikon bagikan di Kantor membuat kartu dengan cuplikan Kantor 3D, langsung ke Instagram (Story atau feed), WhatsApp, TikTok, X, Facebook, Telegram, atau disimpan ke galeri.
- **Taman di Kantor 3D** seperti di desktop.
- **Wake word "Hey Neo"** (opsional, di Profil): model suara diunduh saat diaktifkan dengan **progres unduhan** di notifikasi dan di Profil, mirror GitHub dulu, coba ulang otomatis, dan pesan error yang jelas. Ada pintasan izin jalan di latar dan tampil di atas aplikasi lain (termasuk MIUI).
- **Repo disematkan** di Profil (diambil dari profil GitHub publik) dan **heatmap kontribusi yang ikut warna tema**.
- Kantor 3D di HP dengan kamera yang memuat seluruh ruangan dan berhenti merender saat tab tidak terlihat.
- Avatar tidak lagi tampil sebagai lingkaran kosong saat foto belum termuat.
- APK ditandatangani dengan kunci rilis Neovarch (SHA-256 `7e:cc:ca:cf:…:e6:15`).

### Pasang

- Linux (x64): `curl -fsSL https://raw.githubusercontent.com/Maftuuh1922/neovrach_Agent/main/scripts/install.sh | sh`
- Windows (x64, PowerShell): `irm https://raw.githubusercontent.com/Maftuuh1922/neovrach_Agent/main/scripts/install.ps1 | iex`
- npm (Node 18+): `npm i -g https://github.com/Maftuuh1922/neovrach_Agent/releases/latest/download/neovarch-agent-npm.tgz`

### Unduhan

- Windows (x64): `neovarch-agent-windows-x64-setup.exe` atau `neovarch-agent-windows-x64.zip`
- Linux (x64): `neovarch-agent-linux-x64.AppImage`, `.deb`, atau `.tar.gz`
- Android: `neovarch-agent-android-universal.apk` (bertanda tangan rilis Neovarch, untuk semua HP Android)
