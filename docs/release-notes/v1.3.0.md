## Neovarch Agent 1.3.0

Rilis ini memisahkan Neovarch sepenuhnya dari Hermes: otak sendiri, folder data sendiri, port sendiri, dan tampilan baru.

### Yang baru

- **Core sendiri.** Otak agen di `core/` (perintah `neovarch`, loop agen, tools, sesi, memori, skill, dan gateway `neovarch serve`) ditulis dari nol untuk Neovarch dan tidak berisi kode core Hermes Agent. Hermes Agent dari Nous Research dikreditkan di `NOTICE` sebagai inspirasi desain dan protokol. Aplikasi desktop tetap turunan Hermes Desktop (MIT), dan lisensinya disimpan apa adanya di `desktop/NOTICE`.
- **Data terpisah di `~/.neovarch`** (`%LOCALAPPDATA%\neovarch` di Windows). Neovarch tidak lagi membaca atau mengubah `~/.hermes`, perintah `hermes`, atau gateway Hermes. Keduanya bisa terpasang berdampingan di satu PC.
- **Port remote baru: 9319.** Gateway remote sekarang di port 9319 (9119 tetap milik Hermes). **Aplikasi HP juga harus diperbarui ke 1.3.0**, lalu pindai ulang QR dari desktop sekali. Izinkan port 9319 di firewall bila HP tidak bisa terhubung.
- **Tampilan baru di desktop dan Android:** merah gelap, flat, semua sudut membulat, tanpa gradien dan tanpa warna bawaan Material.

### Pasang

- Linux (x64): `curl -fsSL https://raw.githubusercontent.com/Maftuuh1922/neovrach_Agent/main/scripts/install.sh | sh`
- Windows (x64, PowerShell): `irm https://raw.githubusercontent.com/Maftuuh1922/neovrach_Agent/main/scripts/install.ps1 | iex`
- npm (Node 18+): `npm i -g https://github.com/Maftuuh1922/neovrach_Agent/releases/latest/download/neovarch-agent-npm.tgz`

### Unduhan

- Windows (x64): `neovarch-agent-windows-x64-setup.exe` (installer) atau `neovarch-agent-windows-x64.zip` (portabel, jalankan "Neovarch Agent.exe")
- Linux (x64): `neovarch-agent-linux-x64.AppImage`, `neovarch-agent-linux-x64.deb`, atau `neovarch-agent-linux-x64.tar.gz` (jalankan `./neovarch-agent`)
- Android: `neovarch-agent-android-arm64.apk` untuk kebanyakan HP modern, atau `neovarch-agent-android-universal.apk`

### Yang belum ada / perlu diketahui

- Belum ada voice, MCP, dan cron (tugas terjadwal) di core baru.
- APK Android masih ditandatangani dengan kunci debug. Android mungkin memperingatkan saat memasang, dan pembaruan ke versi bertanda tangan resmi nanti mungkin perlu uninstall dulu.
- Build Windows dan build paket (setup.exe, zip, AppImage, deb) belum diuji di perangkat asli. Pengujian dilakukan di Linux headless.
- Build belum ditandatangani: Windows SmartScreen mungkin meminta konfirmasi ("More info" → "Run anyway").
- Beberapa teks di aplikasi masih berbahasa Inggris.
